In Entwicklung / in development. Gemeinsamer Python-Kern, noch keine Oberfläche.
Inoffiziell, nicht mit Hotta Studio oder Perfect World verbunden, von ihnen
nicht betrieben oder unterstützt. Spielnamen und Marken gehören ihren Inhabern.
